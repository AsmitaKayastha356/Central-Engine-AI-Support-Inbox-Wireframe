Central Engine – AI Support & Inbox Wireframe
A UI/UX prototype for an AI-powered omni-channel customer support dashboard, featuring a unified messaging inbox, knowledge base training tools, and a live widget simulator.
Key Features
Unified Inbox:Manage customer conversations across multiple channels from a single dashboard.
Knowledge Base Training:Train the AI using website URLs and drag-and-drop document uploads.
Live Widget Preview:Test and preview automated AI responses in real-time across different user contexts.
